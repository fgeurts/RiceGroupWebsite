This page contains a bunch of helpful resources on software and computing related aspects, ranging from local computing resources to those that are used at our remote facilities.

* [Rice Slack](https://rice-star.slack.com)  
  web access to Rice RHIC Slack space
* [STAR Mattermost](https://chat.sdcc.bnl.gov/star/)  
  web access to STAR Mattermost Channels (hosted at BNL)
* [NoMachine Setup](https://www.sdcc.bnl.gov/information/services/how-use-nx-sdcc)  
  instructions on how to set up an accelerated graphical Linux environment to SDCC's computing services
* [Jupyter at RACF](https://www.sdcc.bnl.gov/information/services/jupyter)  
  instructions on how to use Jupyter services at BNL
* [Rice Heavy-Ion Repository](https://github.com/orgs/RiceU-HeavyIons)  
  RIce Heavy-Ion Group GitHub repositories
* [STAR Git Repository](https://github.com/star-bnl)  
  STAR Software Stack (star-sw) on GitHub
* [Getting a Computing Account at STAR](https://drupal.star.bnl.gov/STAR/comp/sofi/facility-access/general-access#OtherSteps)  
  Instructions on how to get your STAR accounts set up at BNL (both for new and old users ...)
* [STAR Environment](https://drupal.star.bnl.gov/STAR/comp/sofi/tutorials/envsetup)  
  How to set up your STAR environment at RACF
* [STAR Software](https://drupal.star.bnl.gov/STAR/comp/sofi/installing/OPTSTAR)  
  How to set up the STAR Software Stack
* [Cornell Virtual Workshop](https://cvw.cac.cornell.edu/topics)  
  A bunch of very useful introductory online workshops on topics that range from basic Linux, to programming in C, and more ...
* [Setting up HEP environment on your Mac](https://github.com/JETSCAPE/JETSCAPE/wiki/Manual-installation:-macOS-prerequisites)  
  A basic list of useful HEP tools that you can install on your Mac (h/t JETSCAPE collaboration)
* [Condor Status (defunct)](http://macfrank.rice.edu/condor/condor_status.php?general_opt_machines=on)  
  Status MacSTAR HTCondor (Rice-only, or with "local" credentials)
* [Rice Research Computing](https://www.crc.rice.edu/app/ricelogin.php)  
  Using this link to request an account on NOTS. Local group applications only.
* [Software Carpentry](https://swcarpentry.github.io/git-novice/04-changes.html)  
  This link provides a very nice how-to for GitHub (and friends)
* [STAR Juniors site](https://star-juniors.github.io)  
  An up-to-date collection of relevant links for newcomers (and oldtimers) in STAR
