# Rice Heavy Ion Group Website
This repository tracks the conversion and migration of the RapidWeaver-based website to one that is based on Eleventy's framework.
The first steps are to faithfully migrate all components in such a way that the newly deployed website looks identical to the original.
Next steps will take more advantage of Eleventy's capabilities to format items such as news, galleries, and other formats.
